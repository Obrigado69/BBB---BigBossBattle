# BBB — Ecrã inteiro no telemóvel

1. Extrai o ZIP.
2. No GitHub, abre `obrigado69/BBB---BigBossBattle` > **Code**.
3. Substitui na raiz do repositório os ficheiros `index.html` e `sw.js` pelos que estão neste ZIP, usando **Add file > Upload files** e depois **Commit changes**. Mantém a pasta `assets/`, `config.js` e os restantes ficheiros.
4. Aguarda o GitHub Pages terminar a publicação. Fecha completamente a PWA e volta a abri-la; em caso de versão antiga, abre o site no browser, atualiza e reinicia a PWA.

Este ajuste retira a moldura fixa 390x844 APENAS nos telemóveis; mantém a vista de preview no computador. A arte é esticada para preencher o viewport, o que pode variar ligeiramente as proporções entre telemóveis. Não mexe no backend nem nas regras da batalha.
