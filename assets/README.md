# Grafismo BBB

Extraído das imagens incorporadas nas cinco pranchetas de BBB.ai fornecido pelo utilizador. WebP qualidade 95, nas posições originais de 390 × 844.

Ecrãs: inicial, menu, modos de jogo, lista de personagens e perfil.

Assets: fundo, logótipo, FIGHT, BOSS FIGHT, CHARACTER, MULTIPLAYER, SINGLEPLAYER, seta de voltar, moldura de retrato, divisória, moldura de skill e ícones de ataque, defesa e cura.

Os fundos pretos são intencionais. Texto da interface é dinâmico, com a fonte Cinzel fornecida na mesma pasta do design. A licença acompanha a fonte em Cinzel-OFL.txt.
